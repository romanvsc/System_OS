# Unidad 5 — Ejercicio 3: Gasto devengado y pago parcial

**Ejemplo didáctico original**, creado para estudiar; no es un enunciado de la profesora.

## Enunciado

Se devenga el alquiler del mes por $600 y queda pendiente de pago. Más tarde se pagan $200 en efectivo. Registrá ambas operaciones y calculá la deuda restante.

## Datos y supuestos

Sin impuestos ni intereses. El manual no tiene una cuenta «Alquileres a pagar»; la deuda por una compra que **no es de mercaderías**, en c/c sin documentar, va a **Acreedores varios**.

## Resolución paso a paso

| Asiento | Cuenta | Debe | Haber |
| --- | --- | ---: | ---: |
| 1 | Alquileres perdidos | 600 | |
| | a Acreedores varios | | 600 |
| 2 | Acreedores varios | 200 | |
| | a Caja | | 200 |
| | **Totales** | **800** | **800** |

1. El asiento 1 reconoce la pérdida (devengado) y la deuda por 600.
2. El asiento 2 baja la deuda y la caja en 200; **no** vuelve a registrar el gasto.
3. Mayor de Acreedores varios: Haber 600 − Debe 200 = **saldo acreedor 400**.

## Resultado

Deuda restante: 400. Pérdida por alquiler del período: 600.
