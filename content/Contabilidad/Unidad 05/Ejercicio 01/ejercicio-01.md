# Unidad 5 — Ejercicio 1: Diario y saldo de Caja

**Ejemplo didáctico original**, creado para estudiar; no es un enunciado de la profesora.

## Enunciado

Una empresa recibe un aporte en efectivo de $10.000; compra mercaderías al contado por $2.000 y cobra $1.500 en efectivo por servicios prestados. Registrá las operaciones y calculá el saldo de Caja.

## Datos y supuestos

Sin impuestos. Según el manual, los servicios prestados se registran en **Ventas**.

## Resolución paso a paso

| Asiento | Cuenta | Debe | Haber |
| --- | --- | ---: | ---: |
| 1 | Caja | 10.000 | |
| | a Capital | | 10.000 |
| 2 | Mercaderías | 2.000 | |
| | a Caja | | 2.000 |
| 3 | Caja | 1.500 | |
| | a Ventas | | 1.500 |
| | **Totales** | **13.500** | **13.500** |

1. Mayor de Caja: Debe 10.000 + 1.500 = 11.500; Haber 2.000. **Saldo deudor 9.500.**
2. Activo = Caja 9.500 + Mercaderías 2.000 = 11.500.
3. Comprobación: Activo 11.500 + Resultados negativos 0 = Pasivo 0 + Capital 10.000 + Resultados positivos 1.500 → 11.500 = 11.500.

## Resultado

Saldo de Caja: 9.500 deudor. Patrimonio neto: 11.500.
