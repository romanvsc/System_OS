# Unidad 5: Registración

> Fuente: [UNIDAD5.md](../UNIDAD5.md) (material de la materia). Se reordenó y se quitaron los números de cita. Los nombres de cuentas de los asientos se ajustaron al [Manual de cuentas de la cátedra](../Unidad%2004/Manual%20de%20cuentas.md).

## 1. Normas legales aplicables

- **Código Civil y Comercial de la Nación (CCC):** obliga a llevar contabilidad (art. 320), fija los libros indispensables y sus formalidades, y la conservación por **10 años** (art. 328).
- **Ley General de Sociedades (19.550):** requisitos de cada tipo societario y libros propios (Actas de Asambleas, Registro de Accionistas).
- **Resoluciones Técnicas de la FACPCE** (RT 8, 9, 16, 17…): normas profesionales de valuación y exposición.
- **AFIP (hoy ARCA):** recauda y fiscaliza los tributos; define los comprobantes y exige registros como el Subdiario de IVA Compras y Ventas.

## 2. Sujetos obligados a llevar libros

Deben llevar contabilidad:
- **Todas las personas jurídicas privadas** (sociedades, asociaciones civiles, fundaciones, cooperativas, mutuales, consorcios, etc.).
- Quienes realizan una **actividad económica organizada**.
- Los titulares de una **empresa o establecimiento** comercial, industrial, agropecuario o de servicios.
- Cualquier persona que pida inscribirse y rubricar sus libros.

**Excepciones:** personas humanas con **profesiones liberales** o actividades agropecuarias **no organizadas como empresa**; y actividades que, por su poco volumen, cada jurisdicción decida eximir.

## 3. Libros obligatorios y su finalidad

| Libro | Finalidad | Características |
| --- | --- | --- |
| **Diario** | Registrar **cronológicamente** todas las operaciones, en base a los comprobantes. Cada anotación es un **asiento**. Es de **primera entrada** y **heterogéneo** (todo tipo de operaciones). | Encuadernado, **foliado** y **rubricado**. No se puede alterar el orden, dejar espacios, borrar, tachar, enmendar ni arrancar hojas. |
| **Inventarios y Balances** | Transcribir el **patrimonio inicial** y, al cierre de cada ejercicio, el inventario y los **estados contables** (más informes del síndico y auditor). Es de **segunda entrada**. | Encuadernado, foliado y rubricado. No puede reemplazarse por medios electrónicos. |

**Otros libros obligatorios por normas especiales:** Subdiarios de IVA Compras y Ventas (AFIP), Registro Único de Trabajo (ley laboral), libros societarios (LGS).

## 4. Funciones de los libros

- **Contable:** registro ordenado y completo de las operaciones; base para los estados contables; herramienta de **control interno**; datos para tomar decisiones; clasifica y cuantifica en moneda.
- **Legal:** cumplir las normas fiscales y evitar sanciones; **medio de prueba en juicio** (si están en forma; si no, prueban en contra); en una quiebra, libros en regla evitan que se la considere fraudulenta; permiten pedir **concurso (convocatoria) de acreedores**; obligación de conservarlos.

## 5. Orden de utilización de los registros

El proceso contable va de la **entrada** (comprobantes) al **procesamiento** (clasificar, registrar, calcular) y a la **salida** (informes).

1. **Comprobantes** → origen de todo registro.
2. **Libro Diario** (o **Subdiarios**): primer registro.
   - **Subdiarios:** diarios auxiliares **homogéneos** para operaciones repetitivas (Caja, Ventas, Compras). Permiten dividir el trabajo y simplifican el pase al mayor. Son de primera entrada.
3. **Libro Mayor** (o «cuentas»): **eje del sistema**. Toma los datos del diario y los **agrupa por cuenta**, mostrando débitos, créditos y **saldo** de cada una. Es **homogéneo** y de **segunda entrada**. No es obligatorio por ley, pero es habitual.
   - **Submayores (subcuentas):** desagregan una cuenta colectiva del mayor (ej.: «Clientes» → Cliente Carla, Cliente Mauro). Permiten control analítico.
4. **Balance de sumas y saldos** (con los ajustes de cierre).
5. **Libro de Inventarios y Balances:** se transcriben el inventario y los estados contables del cierre.

## 6. Sistemas y medios de registración

**Sistema de registración:** es la **coordinación de un conjunto de comprobantes, cuentas y registros** (y los procedimientos para usarlos) que permite procesar los datos y obtener la información contable.

**Medios de registración** (cómo se escriben los registros):
- **Manual (manuscrito):** a mano. Fue el más usado; hoy en desuso por lento.
- **Mecánico:** máquinas de escribir y calculadoras (años 40 a 70). Más rápido que el manual, pero sin almacenamiento de información.
- **Simultáneo / computarizado (procesamiento electrónico):** software contable (Tango, Bejerman…). Un solo ingreso de datos actualiza a la vez diario, mayor y demás registros; es rápido, confiable y almacena la información.

## 7. Registración de las operaciones más habituales

Formato del asiento: fecha, cuentas que se debitan, cuentas que se acreditan (precedidas por «a»), importes y leyenda «P/R» (por registro).

**Constitución con aportes de activos (unipersonal).** Carla Páez aporta efectivo $20.000, muebles $50.000 y mercaderías $30.000:

| Cuenta | Debe | Haber |
| --- | ---: | ---: |
| Caja | 20.000 | |
| Muebles y útiles | 50.000 | |
| Mercaderías | 30.000 | |
| a Capital | | 100.000 |

**Constitución de una sociedad (suscripción e integración).** Palmares SRL: Lamadrid aporta $40.000 en efectivo y un rodado de $60.000; Páez un inmueble de $150.000 (excede en $50.000 su compromiso de $100.000):

| Cuenta | Debe | Haber |
| --- | ---: | ---: |
| Socio Lamadrid cuenta aporte | 100.000 | |
| Socia Páez cuenta aporte | 100.000 | |
| a Capital | | 200.000 |
| *P/R suscripción* | | |
| Caja | 40.000 | |
| Rodados | 60.000 | |
| a Socio Lamadrid cuenta aporte | | 100.000 |
| *P/R integración de Lamadrid* | | |
| Inmuebles | 150.000 | |
| a Socia Páez cuenta aporte | | 100.000 |
| a Socia Páez cuenta particular | | 50.000 |
| *P/R integración de Páez con exceso* | | |

**Compra de mercaderías al contado** ($10.000): Mercaderías 10.000 / a Caja 10.000.

**Compra mitad contado, mitad en cuenta corriente** ($6.000): Mercaderías 6.000 / a Caja 3.000 / a Proveedores 3.000.

**Venta al contado** ($10.000, costo $6.000) — dos asientos:

| Cuenta | Debe | Haber |
| --- | ---: | ---: |
| Caja | 10.000 | |
| a Ventas | | 10.000 |
| Costo de mercaderías vendidas | 6.000 | |
| a Mercaderías | | 6.000 |

**Pago de un servicio** (gas $2.500): Gastos generales 2.500 / a Caja 2.500. *(La fuente usa la cuenta «Luz, gas y teléfono»; el manual indica Gastos generales para importes bajos y una cuenta propia si son elevados.)*

**Pago a proveedores con cheque** ($1.000): Proveedores 1.000 / a Banco X c/c 1.000.

**Cobro a un cliente:** Caja / a Deudores por ventas.

**Depósito de efectivo en el banco** ($4.000): Banco X c/c 4.000 / a Caja 4.000.

**Documentar una deuda** (pagaré a 60 días por $200): Acreedores varios 200 / a Documentos a pagar 200.

En todos los casos **el total del Debe es igual al total del Haber**. Después se pasa cada importe al **mayor**, se calcula el saldo de cada cuenta y se comprueba la igualdad:

```text
ACTIVO + RESULTADOS NEGATIVOS = PASIVO + CAPITAL + RESULTADOS POSITIVOS
```

(Las regularizadoras se restan de la cuenta que ajustan.)
