# Unidad 3 — Ejercicio 3: Devengado y cobro

**Ejemplo didáctico original**, creado para estudiar; no es un enunciado de la profesora.

## Enunciado

Un servicio por $3.000 se presta en diciembre y se cobra en enero. Registrá según la base devengado y explicá qué cambiaría con la base percibido.

## Datos y supuestos

Sin impuestos. Según el manual, los servicios prestados se registran en **Ventas** y el crédito en **Deudores por ventas**.

## Resolución paso a paso

| Fecha | Cuenta | Debe | Haber |
| --- | --- | ---: | ---: |
| Diciembre | Deudores por ventas | 3.000 | |
| | a Ventas | | 3.000 |
| Enero | Caja | 3.000 | |
| | a Deudores por ventas | | 3.000 |

1. **Diciembre (devengado):** el servicio ya se prestó: se reconoce la ganancia y el derecho a cobrar. Es una variación modificativa aumentativa.
2. **Enero:** el cobro cambia un activo por otro (permutativa). **No** se vuelve a registrar la venta.
3. **Base percibido:** el ingreso se registraría recién en enero, al cobrar. La contabilidad en Argentina usa la base devengado.

## Resultado

El ingreso corresponde a diciembre; en enero solo hay un cobro.
